# Локализация

Встроенные словари `ru-RU` и `en-US` находятся в `src/ui/Localization.cpp`.
Любой файл `<язык>.json` в этом каталоге (плоский объект `"ключ": "строка"`)
накладывается поверх встроенных строк; новый код языка (например `uk-UA.json`)
автоматически появляется в меню «Вид → Язык». Ключи окон содержат суффикс
`###Id` — его нужно сохранять, иначе собьётся раскладка док-панелей.

Пример `en-US.json`:

```json
{ "menu.file": "File", "welcome.subtitle": "My custom subtitle" }
```
