# Шрифты

Положите сюда `JetBrainsMono-Regular.ttf` (или `DejaVuSansMono.ttf`) — он будет
использован в первую очередь. Иначе IDE ищет системные моноширинные шрифты
(Cascadia Mono / Consolas, Menlo, DejaVu Sans Mono, Liberation Mono).
Подгружаются глифы латиницы, кириллицы, стрелок и псевдографики терминала.
